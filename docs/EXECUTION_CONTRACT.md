# 정석몰 실행 계약

## 추적 ID

| 대상 | ID |
|---|---|
| 웹 요청 | `request_id` |
| 주문 | `order_id` |
| 결제 시도 | `payment_attempt_id` |
| 상담 실행 | `agent_run_id` |
| 상세페이지 생성 | `job_id` + `detail_page_version_id` |
| 쇼츠 렌더 | `job_id` + `render_job_id` |

## 상태 원칙

- 외부 API 호출 전과 후의 상태를 분리합니다.
- 생성 요청과 승인·게시를 분리합니다.
- 같은 멱등 키의 주문·결제·작업은 한 번만 효력을 냅니다.
- 작업 실패를 성공으로 표시하지 않습니다.
- 사람이 승인한 상세페이지와 쇼츠만 공개·다운로드 상태가 됩니다.

## 로그 금지값

- 공급자 API 키와 인증 헤더
- 전체 배송 주소·전화번호
- 토스페이먼츠 시크릿 키
- 세션 서명 비밀과 암호화 최상위 키
- queue에서 복호화된 자격증명
