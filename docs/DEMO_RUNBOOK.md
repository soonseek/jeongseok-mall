# 정석몰 데모 실행서

## 고객 흐름

1. `/account`에서 공개 데모 고객으로 로그인합니다.
2. 상품을 장바구니에 넣고 `/checkout`으로 이동합니다.
3. 토스 테스트 키가 설정되어 있으면 테스트 결제창을 실행합니다.
4. 승인 뒤 `/account`에서 본인 주문만 확인합니다.
5. 정석 상담에 배송 정책, 내 주문 상태, 상담원 이관을 요청합니다.

공개 데모 고객은 `demo@jeongseok.test` / `DemoCustomer1234`입니다. 실제 개인정보·주소·결제정보를 입력하지 않습니다.

## 관리자 흐름

1. 최초 한 번 `/admin/setup`에서 최고 관리자를 만듭니다.
2. `/admin/products`에서 상품과 팩트·근거를 등록합니다.
3. `/admin/content`에서 상세페이지 초안을 만들고 문장·SEO를 수정합니다.
4. 검수 요청 → 승인 → 게시 순서로 진행합니다.
5. 승인된 버전에서 15초 또는 30초 쇼츠 대본을 만들고 훅·음성·화면 자막을 수정합니다.
6. MP4 렌더 후 MP4·SRT·PNG·대본·매니페스트를 다운로드합니다.
7. `/admin/support`에서 이관 티켓과 모델·도구 실행 기록을 확인합니다.

콘텐츠 담당자는 생성·수정·검수 요청을 할 수 있고, 관리자만 승인·게시합니다. 최고 관리자만 담당자 계정과 공급자 키를 변경합니다.

## 확인된 로컬 산출물

- 상세페이지 게시 버전이 공개 상품 상세에 반영
- H.264/AAC, 1080×1920, 30fps, 정확히 15초인 MP4
- macOS 음성 합성, 안전영역 PNG 번인 자막, 별도 SRT
- 썸네일 PNG와 상품·상세 버전·렌더 설정 매니페스트
