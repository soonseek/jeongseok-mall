# 정석몰 쇼츠 스타일 v1

## 캔버스

- 1080×1920, 30fps
- 핵심 텍스트 안전 영역: x 72–1008, y 120–1540
- 하단 380px에는 플랫폼 UI와 캡션이 겹칠 수 있으므로 가격·CTA 외 핵심 정보를 두지 않는다.

## 브랜드

- 기본 폰트: Pretendard
- 강조 영문: Playfair Display
- 배경: `#f6f6f2`, `#111318`
- 프라이머리: `#0047ff`
- 보조 강조: `#c8ff45`
- 큰 제목은 86px 이상, 자막은 58px 이상을 기본으로 한다.

## 텍스트

- 첫 3초 훅: 최대 18자, 최대 2줄
- 자막: 최대 2줄, 줄당 16자 권장
- 한 화면에는 하나의 주장만 둔다.
- 가격·치수·재질·호환성은 생성형 영상 안에 넣지 않고 코드 레이어로 그린다.
- `최고`, `완벽`, `무조건`, `100%`처럼 검증할 수 없는 절대 표현을 금지한다.

## 연출

- 발화 의미가 끝나는 지점에서 컷을 바꾼다.
- 한 샷은 1.5–4초를 기본으로 한다.
- 제품의 사용 전 상황 → 손의 행동 → 사용 후 결과 순서를 우선한다.
- 글로우 남용, 의미 없는 HUD, 임의 게이지, 과도한 3D 카드 회전을 금지한다.
- 숫자, 차트, 가격, CTA는 Remotion 컴포넌트로 정확하게 렌더한다.

## 제품 사실성

- 승인된 제품 이미지는 변형하지 않는다.
- 생성 배경과 합성한 경우 매니페스트에 이를 기록한다.
- 제품 외형이 달라진 장면, 가짜 로고, 존재하지 않는 구성품은 폐기한다.
