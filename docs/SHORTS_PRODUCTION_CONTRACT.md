# 정석몰 상품 소개 쇼츠 생산 계약 v1

이 문서는 정석몰이 상품 소개 쇼츠를 만들 때 에이전트, 관리자 화면, 렌더러가 함께 지켜야 하는 실행 계약이다. 원카AI Wonka 채널의 숏츠 제작 관련 공개 영상 자막을 분석해 얻은 원리를 정석몰의 상품 사실성·보안·승인 정책에 맞게 재설계했다.

## 산출물

한 프로젝트는 다음 파일과 기록이 모두 있어야 `READY`가 된다.

- 9:16 MP4: 1080×1920, 15초 또는 30초
- SRT 자막
- 씬·샷별 대본 JSON
- 사용한 상품 사실 ID와 출처
- 에셋 목록과 생성 이력
- 렌더 매니페스트: 버전, 폰트, 컬러, 모델, 프롬프트 해시
- 대표 프레임과 썸네일 후보
- 자동 검수 보고서와 관리자 승인 이력

## 그래프

`PRODUCT_FACTS → ANGLE → HOOKS → SCRIPT → SCENES → SHOTS → ASSETS → APPROVAL → GENERATION → QC → RENDER → HUMAN_APPROVAL`

앞 단계가 바뀌면 영향을 받은 뒤 단계만 무효화한다. 예를 들어 가격이 바뀌면 가격을 쓰는 자막·렌더만 다시 만들고, 승인된 제품 원본과 배경 에셋은 유지한다.

## 기본 구성

### 15초

- 0–2초: 결과 또는 불편을 한 화면으로 보여주는 훅
- 2–6초: 사용 전 상황
- 6–11초: 제품 사용과 핵심 변화
- 11–13초: 검증된 사실 1–2개
- 13–15초: 행동 하나

### 30초

- 0–3초: 결과 훅
- 3–8초: 구체적인 사용 전 상황
- 8–18초: 사용 장면 2–3개
- 18–24초: 제품 사실과 조건
- 24–27초: 누구에게 맞는지
- 27–30초: 행동 하나

## 제품 시각 잠금

- 승인된 원본 사진을 마스터 에셋으로 지정한다.
- 제품의 색, 비율, 로고, 구멍·버튼·포트 수, 구성품을 잠금 항목으로 기록한다.
- 제품과 배경을 한 번에 생성하지 않고 `배경 생성 → 제품 합성 → 시작·종료 프레임 고정 → 영상화`를 우선한다.
- 사실성 검사를 통과하지 못한 생성물은 공개·렌더 대상에서 제외한다.

## 승인 게이트

외부 API를 사용하는 작업은 실행 버튼 바로 위에 다음 내용을 보여주고 관리자가 승인해야 한다.

- 전송 대상 공급자
- 전송되는 상품 정보와 이미지
- 예상 호출 횟수와 비용
- 생성 모델과 해상도
- 프롬프트 전문

승인 기록에는 사용자, 시각, 대상 데이터, 프롬프트 해시를 남긴다. 키는 브라우저로 다시 노출하지 않는다.

## 자동 검수

| 검사 | 실패 조건 |
|---|---|
| 상품 일관성 | 잠근 외형이 바뀌거나 다른 제품처럼 보임 |
| 주장 근거 | 화면·발화 문구가 승인된 상품 사실과 연결되지 않음 |
| 자막 | 잘림, 안전 영역 침범, 발화와 350ms 이상 지속적으로 어긋남 |
| 장면 연결 | 인물·제품·방향·배경이 이유 없이 급변함 |
| 오디오 | 긴 무음, 클리핑, 원치 않는 음성·음악이 존재함 |
| 출력 | 9:16, 지정 길이, 해상도, 코덱 조건을 만족하지 않음 |

자동 검수 통과는 공개 승인이 아니다. 관리자가 실제 MP4를 재생하고 승인해야 상품 페이지나 채널에 사용할 수 있다.

## 스타일 MD

렌더러는 별도의 `SHORTS_STYLE.md`를 읽어 브랜드를 적용한다. 스타일 문서에는 컬러와 폰트뿐 아니라 다음을 포함한다.

- 첫 3초 텍스트 최대 글자 수
- 자막 최대 두 줄과 줄당 글자 수
- 화면 하단 UI 안전 영역
- 가격·스펙·주의 문구 컴포넌트
- 허용하는 전환과 금지하는 AI식 효과
- 실제 제품 이미지와 생성 배경의 표기 방식
